# Air Draw

Draw in the air with your finger using your webcam.

Built with Python, OpenCV and MediaPipe.

## How to use

- Index finger up: draw
- Index + middle finger up: move without drawing

| Key | Action |
|---|---|
| 1 / 2 / 3 | Red / Green / Blue |
| e | Eraser |
| c | Clear |
| q | Quit |

## Run it

Needs Python 3.9 to 3.12.

```bash
git clone https://github.com/Fouad-dev101/Air-draw.git
cd Air-draw
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
